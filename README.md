# Homebrew tap

Install Pureblood & Prejudice, an unofficial, non-commercial Harry Potter fan visual novel, on macOS (Apple Silicon or Intel):

```sh
brew install --cask cocolemontv/tap/pureblood-and-prejudice
```

Update with `brew upgrade`. The app isn't signed by Apple, so on first launch right-click it in Applications and choose **Open**.

Not affiliated with or endorsed by Warner Bros., J.K. Rowling or any rights holder. Other downloads: [Releases](https://github.com/CocolemonTV/pureblood-and-prejudice-releases/releases).
